PixelNorte
Es un sitio web desarrollado para el trabajo practico de los modulos 4 y 5 vistos en clases donde practicamos
tecnologias como html, css, y aplicamos los repositorios en localcon git y en la nube con github.

Descripcion:
PixelNorte es un sitio web orientado a ofecer servicios de diseño web , marketing digital y soporte
la estructura del proyecto es un directorio ppixelnorte donde se alojan todos los archivos vinculados al mismo
(html,css,img,etc) mas alla de que en este proyecto en si algunas cosas como imagenes no se utilizaron.
Esta compiuesto por una pagina principal , desde la cual podemos viajar al resto de las paginas pedidas en el proyecto,
donde se utilizan tablas, formularios, naavegacion entre paginas, diseño responsive movile y uso de flexbox y css grid
Se utilizarpon repositorios como git y github.
